```sh
arp -a
```
- Used to identify devices in the network along with IP and MAC
- But can be used only if there is a traffic recently initiated between to the target. *Ex: ping*
- If no initial ping to target has been initiated, it will not show in the results.
- For complete scan use [[netdiscover]]
