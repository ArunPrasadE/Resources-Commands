```sh
locate <file-name>
```
- This is a linux command which we can use to locate the target file/name. It will give the complete directory path.
- I think this is similar to `find` command. `find . -name "file-name"`. This will search for the file name in the current directory and its sub-directories.
- In contrast `locate` searches the entire linux directories
